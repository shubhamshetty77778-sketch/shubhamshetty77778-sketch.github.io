# Shubham Shetty — Every Frame Has a Story

Cinematic editing, cinematography and visual storytelling portfolio.

## Publish on GitHub Pages

In Settings → Pages, choose Deploy from a branch, main, /(root), and Save.

Website: https://shubhamshetty77778-sketch.github.io/

The HTML, CSS, JavaScript, local fonts, GSAP, images and software logos are ready to serve without a build step. Push changes to main to update GitHub Pages once enabled.

The contact button opens WhatsApp. The contact form prepares an email draft; it does not send messages from a backend. Résumé is available on request.
