Sign in

The app saves your changes to the website's files on GitHub. It needs a key from GitHub once; the key stays on this phone only.

  1. Open GitHub → new fine-grained token (signed in to the account that owns the website).
  2. Name it "Studio app" and pick an expiry (a year is fine).
  3. Repository access: Only select repositories → shubhamshetty77778-sketch.github.io.
  4. Permissions → Repository: Contents: Read and write, and Actions: Read-only (to see progress).
  5. Generate the token, copy it, and paste it below.
