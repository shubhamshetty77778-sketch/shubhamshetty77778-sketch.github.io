YOUR PORTFOLIO / NEXT STEPS

Ready for
your work.

The structure is built. Add your original films and images to make this portfolio yours.

Add a project

  1. Download the source code below and extract it.
  2. Place your images and short preview videos in dist/assets/.
  3. Open projects.json. Duplicate a project object and give it a unique slug.
  4. Add your title, category, roles, verified details and media paths. Set placeholder to false. Use featured: true to include it on the homepage.
  5. Run python3 build.py. All pages are generated from the shared templates and content.
  6. Deploy the dist folder to a static host, or ask for this Site to be updated using your new files.

Keep adding stories

Reorder the objects in projects.json to rearrange work. Remove an object to remove that project from the galleries. The Short Films category sends a project to the screening room.

Each project supports a thumbnail, preview video, full video link, gallery, brief, approach, process, tools and verified outcome. Short films also support genre, duration, synopsis and credits.

Contact & privacy

The contact form creates an email draft and includes a copy fallback. It does not send or store messages. A direct submission service can be connected later. This Site starts private; public sharing must be enabled before sending it to recruiters.

Run locally

python3 build.py
python3 -m http.server 8000 --directory dist
Then open http://localhost:8000.

This site uses HTML, CSS, JavaScript and locally bundled GSAP with ScrollTrigger. Python is only needed to regenerate pages.
